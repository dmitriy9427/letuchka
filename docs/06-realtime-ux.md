# 06. Реальное время в интерфейсе

## Курсоры коллег (`CursorLayer.vue`)

**Координаты.** У всех разная ширина экрана, поэтому `x` передаётся долей
ширины доски (0…1), а `y` — пикселями от её верха (колонки растут вниз
одинаково). На стороне получателя: `x × ширина его доски`.

**Частота.** `pointermove` срабатывает до 120 раз в секунду. По сети столько
не нужно — функция `throttle` отправляет не чаще раза в 50 мс (20 в секунду),
не теряя последнюю точку.

**Плавность.** Между обновлениями курсор «прыгал» бы. CSS
`transition: transform 0.12s linear` сглаживает движение между точками.

**Уход.** Курсор, который не двигался 8 секунд, прячется.

## Таймер без постоянных сообщений (`RoomTimer.vue`)

Плохой вариант: ведущий каждую секунду рассылает «осталось 2:59, 2:58…».
Хороший: в комнате хранится **момент окончания** (`timerEnd`), а каждый
клиент сам считает `timerEnd − сейчас`. Одно сообщение на запуск, таймер
одинаковый у всех и не сбивается от задержек сети. (Расхождение — только на
разницу часов устройств, обычно доли секунды.)

`useNow(250)` — composable с текущим временем, обновляется 4 раза в секунду.

## Этапы

Этап — поле комнаты, менять его может только ведущий (кнопки у остальных
`disabled`, а в Supabase — правило RLS). Этап меняет поведение:

| Этап | Что можно |
| --- | --- |
| Пишем | добавлять и править свои карточки; чужие размыты |
| Голосуем | по 3 голоса, можно снять и переложить |
| Обсуждаем | карточки сортируются по голосам; ведущий выделяет обсуждаемую |

## Фокус

Ведущий нажимает «Обсуждаем» — `focusCardId` комнаты меняется, и у всех эта
карточка поднимается с пульсирующей рамкой. Удобно на созвоне: все смотрят в
одну точку.

## Реакции

Эмодзи — эфемерное сообщение Broadcast, в базу не пишется. У получателя
добавляется в список, CSS-анимация уносит его вверх, через 2,6 с элемент
удаляется. Горизонталь вычисляется из id реакции — у всех одинаковая.
