## С чего начать учить Vue на этом проекте

1. Прочитать главу 01.
2. Открыть `app/components/NoteCard.vue` — в нём есть почти всё: пропсы,
   `computed`, `ref`, `nextTick`, директивы, scoped-стили.
3. Поменять что-нибудь маленькое: цвет колонки, текст подсказки, число
   голосов (`VOTES_PER_USER` в `app/lib/board.ts`) — и посмотреть, что
   изменится.
4. Добавить фичу самому, например кнопку «Удалить все мои карточки» или
   четвёртую колонку. Тесты (`npm test`) подскажут, если что-то сломалось.
